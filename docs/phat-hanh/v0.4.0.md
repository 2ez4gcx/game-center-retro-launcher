## Có gì mới

- **PSP** (core PPSSPP): chép file `.iso` / `.cso` của game PSP vào thư mục game là chơi, không cần BIOS. Game Center tự nhận là game PSP theo nội dung file, dựng hình nét gấp 3 lần máy thật. Lưu và "chơi tiếp" như các hệ khác.
- **Tự giải nén game đĩa trong file .zip**: game PS1 / PS2 / PSP còn nằm trong file zip trước đây chỉ được báo "phải giải nén". Giờ Game Center hỏi và giải nén giúp, tất cả các file trong một lần bấm (tiện cho game nhiều đĩa, mỗi đĩa một file zip). File zip gốc được giữ nguyên.
- **Dùng save từ giả lập khác**: **⋯ → Dùng save từ giả lập khác**.
  - PS1: thẻ nhớ `.mcr`, `.mcd`, `.mc`, `.gme`, `.vmp`, `.mem` (ePSXe, DuckStation, PCSX, DexDrive, PSP / PS3).
  - Máy băng (NES, SNES, Game Boy, GBA, Mega Drive...): file `.sav` / `.srm`.
  - Để file save cạnh file game, cùng tên (`Game.gba` + `Game.sav`), thì lần chơi đầu Game Center tự dùng. Save đang có luôn được sao lưu trước khi thay.
- Tên game kiểu danh mục "Legend of Dragoon, The" hiện thành "The Legend of Dragoon".
- **Bản Android (thử nghiệm)** phát hành riêng: xem [Game Center Android – bản thử 1](https://github.com/2ez4gcx/game-center-retro-launcher/releases/tag/android-preview-1).

## Nâng cấp từ 0.3.0

Chạy bộ cài mới đè lên bản cũ (Next → Finish). Game, save, chỗ đang chơi, yêu thích và lịch sử chơi giữ nguyên. File game PSP trước đây nằm ở mục "Chưa nhận ra" sẽ tự chuyển sang mục PSP sau lần quét đầu.

## Lưu ý

- **PSP** đã chạy thử trên Windows với một game thật (vào trận đấu 3D, lưu chỗ đang chơi, chơi tiếp). Chưa thử trên macOS và Linux, chưa thử file `.cso`.
- **Giải nén game đĩa trong zip** đã chạy thử trên Windows với một game 4 đĩa thật.
- **Dùng save từ giả lập khác** có kiểm thử tự động cho mọi định dạng nêu trên; trên máy tính chưa thử bằng tay với save thật. Không đọc được "chỗ đang chơi" (save state) của giả lập khác, và chưa hỗ trợ thẻ nhớ PS2.
- Bản **macOS và Linux** đã build và qua kiểm thử tự động, nhưng **chưa chạy thử trên máy thật**. Gặp lỗi xin [mở issue](https://github.com/2ez4gcx/game-center-retro-launcher/issues) kèm file `Logs/gamecenter.log`.
- Bộ cài Windows được thử tự động trên máy Windows sạch: cài, gỡ cài đặt (game và save còn nguyên), cài lại, chạy game với RetroArch trong bộ cài.
- **PS2** cần máy khá mạnh và BIOS của bạn. Game Center không kèm game hay BIOS.

# English

[Tiếng Việt](#có-gì-mới) · **English**

## What's new

- **PSP** (PPSSPP core): copy a PSP game's `.iso` / `.cso` file into the games folder and play, no BIOS needed. Game Center recognizes PSP games by file content and renders at 3x the original resolution. Saving and "Continue" work like on the other consoles.
- **Built-in extraction of disc games in .zip files**: PS1 / PS2 / PSP games still inside a zip used to be reported as "must be extracted". Game Center now offers to extract them for you, all files in one click (handy for multi-disc games with one zip per disc). The original zip files are kept.
- **Use a save from another emulator**: **⋯ → Use a save from another emulator**.
  - PS1: memory cards `.mcr`, `.mcd`, `.mc`, `.gme`, `.vmp`, `.mem` (ePSXe, DuckStation, PCSX, DexDrive, PSP / PS3).
  - Cartridge consoles (NES, SNES, Game Boy, GBA, Mega Drive...): `.sav` / `.srm` files.
  - Put the save next to the game file with the same name (`Game.gba` + `Game.sav`) and Game Center uses it on first play. The current save is always backed up before being replaced.
- Catalogue-style names such as "Legend of Dragoon, The" are shown as "The Legend of Dragoon".
- **Android version (experimental)** is released separately: see [Game Center Android – preview 1](https://github.com/2ez4gcx/game-center-retro-launcher/releases/tag/android-preview-1).

## Upgrading from 0.3.0

Run the new installer over the old version (Next → Finish). Games, saves, places in games, favorites and play history are kept. PSP game files that used to sit under "Not recognized" move to the PSP list after the first scan.

## Notes

- **PSP** was tried on Windows with one real game (a 3D match, saving the place, continuing). Not yet tried on macOS or Linux, nor with `.cso` files.
- **Extracting disc games from zip** was tried on Windows with a real 4-disc game.
- **Saves from other emulators** have automated tests for every format listed; on desktop it has not been tried by hand with a real save. Save states from other emulators cannot be read, and PS2 memory cards are not supported yet.
- The **macOS and Linux** builds are built and pass automated tests but have **not been run on real machines**. If something breaks, please [open an issue](https://github.com/2ez4gcx/game-center-retro-launcher/issues) with the `Logs/gamecenter.log` file.
- The Windows installer is tested automatically on a clean Windows machine: install, uninstall (games and saves stay), reinstall, run a game with the bundled RetroArch.
- **PS2** needs a fairly powerful computer and your own BIOS. Game Center includes no games and no BIOS.
