## Có gì mới

- **Game thùng (máy thùng, arcade)** bằng FinalBurn Neo: Neo Geo, Capcom CPS1/CPS2/CPS3, PGM, Cave, Konami... Chép file zip của game vào là chơi. Game Center hiện tên đầy đủ (`dino.zip` → Cadillacs and Dinosaurs), báo trước nếu thiếu BIOS (`neogeo.zip`, `pgm.zip`), thiếu bản gốc hay bộ ROM khác phiên bản, và nhắc cách bỏ xu ở lần chơi đầu.
- **PS2** (core LRPS2). Cần BIOS sao lưu từ máy PS2 của bạn: chép vào thư mục `BIOS`, Game Center tự nhận theo nội dung và đặt đúng chỗ.
- **Tiếng Anh**: giao diện, bộ cài và menu RetroArch theo ngôn ngữ chọn; nút 🌐 đổi ngay.
- **Master System / Game Gear**.
- **Nhận diện game tốt hơn**:
  - Đĩa PS1 / PS2 phân biệt theo nội dung, không cần xếp thư mục.
  - Đọc được `.bin` lẻ, `.zip` nhiều ROM, `.chd`, `.cso`, `.pbp`.
  - File cần giải nén (`.7z`, `.rar`, nén nhiều phần...) được báo rõ cách xử lý.
- **Game nhiều đĩa**: tự ghép, kể cả bản Việt hóa chia mỗi đĩa một thư mục. Đổi đĩa ngay khi đang chơi, mọi đĩa dùng chung thẻ nhớ, lần sau mở lại đúng đĩa đang chơi. Các đĩa khác tên (đĩa 1 Việt hóa, đĩa sau bản gốc) thì ghép tay bằng **⋯ → Ghép thêm đĩa**.
- **Bảo toàn save**:
  - Tự sao lưu trước mỗi lần chơi (giữ 10 bản gần nhất); khôi phục bằng **⋯ → Khôi phục save cũ**.
  - Save tự đi theo khi đổi tên file, ghép thêm đĩa, đổi thư mục dữ liệu.
  - Cảnh báo khi ổ chứa save sắp đầy.

## Sửa lỗi quan trọng

- Máy băng (NES, SNES, Game Boy...): "Chơi tiếp" có thể kéo save trong game về bản cũ (lỗi có từ 0.2.0). Đã sửa, kèm kiểm thử với RetroArch thật.
- Các game trùng tên file (nhiều `EBOOT.PBP`, `game.cue` ở các thư mục khác nhau) từng dùng chung một thẻ nhớ và ghi đè save của nhau. Giờ mỗi game có save riêng.
- Nâng cấp từ bản 0.1.0: save mang tên game (cách đặt tên cũ) được nhận lại.
- Máy không có driver Vulkan (máy ảo, Remote Desktop, card đồ họa cũ) mà vẫn có file `vulkan-1.dll`: game PS1 / PS2 trước đây không mở được. Giờ Game Center kiểm tra Vulkan thật và dùng Direct3D 11 khi không có.

## Nâng cấp từ 0.2.0

Chạy bộ cài mới đè lên bản cũ (Next → Finish). Game, save, chỗ đang chơi, yêu thích và lịch sử chơi giữ nguyên. Đã thử nâng cấp trên bản sao dữ liệu 0.2.0 thật: không mất game hay file save nào, mọi game nạp đúng thẻ nhớ. Lần đầu chơi mỗi game, Game Center sao lưu save trước.

- Bản **macOS và Linux** đã build và qua kiểm thử tự động, nhưng **chưa chạy thử trên máy thật**. Gặp lỗi xin [mở issue](https://github.com/2ez4gcx/game-center-retro-launcher/issues) kèm file `~/GameCenter/Logs/gamecenter.log`.
- Bộ cài Windows đã được thử tự động trên máy Windows sạch: cài, gỡ cài đặt (game và save còn nguyên), cài lại, chạy game với RetroArch trong bộ cài.
- **Game thùng** đã thử với core FinalBurn Neo thật, chưa thử với ROM game thật. Nên dùng bộ ROM dành cho FinalBurn Neo.
- **PS2** cần máy khá mạnh và BIOS của bạn. Game Center không kèm game hay BIOS.

## What's new

- **Arcade games** with FinalBurn Neo: Neo Geo, Capcom CPS1/CPS2/CPS3, PGM, Cave, Konami... Copy a game's zip file in and play. Game Center shows the full name (`dino.zip` → Cadillacs and Dinosaurs), warns up front about a missing BIOS (`neogeo.zip`, `pgm.zip`), a missing parent set or a ROM set from another version, and explains how to insert a coin the first time you play.
- **PS2** (LRPS2 core). Needs a BIOS dumped from your own PS2: copy it into the `BIOS` folder and Game Center recognizes it by content and puts it where the core looks.
- **English**: interface, installer and RetroArch menu follow the chosen language; the 🌐 button switches instantly.
- **Master System / Game Gear**.
- **Better game detection**:
  - PS1 and PS2 discs are told apart by content, no folders needed.
  - Loose `.bin`, multi-ROM `.zip`, `.chd`, `.cso` and `.pbp` files are recognized.
  - Files that need extracting (`.7z`, `.rar`, multi-part archives...) come with clear instructions.
- **Multi-disc games**: merged automatically, including fan translations with one folder per disc. Swap discs while playing, all discs share one memory card, and the game reopens on the disc you were playing. Discs with different names (translated disc 1, original later discs) can be merged by hand with **⋯ → Add another disc**.
- **Save protection**:
  - Automatic backup before every play (last 10 kept); restore with **⋯ → Restore an older save**.
  - Saves follow renamed files, added discs and a changed data folder.
  - Warning when the drive holding your saves is almost full.

## Important fixes

- Cartridge systems (NES, SNES, Game Boy...): "Continue" could roll in-game saves back to an older copy (a 0.2.0 bug). Fixed, with tests against the real RetroArch.
- Games with the same file name (several `EBOOT.PBP`, `game.cue` in different folders) used to share one memory card and overwrite each other's saves. Each game now has its own.
- Upgrading from 0.1.0: saves named after the game title (the old naming) are picked up again.
- Computers without a Vulkan driver (virtual machines, Remote Desktop, old graphics chips) that still have `vulkan-1.dll`: PS1 / PS2 games used to fail to start. Game Center now checks that Vulkan really works and uses Direct3D 11 otherwise.

## Upgrading from 0.2.0

Run the new installer over the old version (Next → Finish). Games, saves, places in games, favorites and play history are kept. The upgrade was tested on a copy of real 0.2.0 data: no game or save file was lost, and every game loaded the right memory card. The first time you play each game, Game Center backs up its saves first.

## Notes

- The **macOS and Linux** builds pass the automated tests but have **not been tried on real machines yet**. If something goes wrong, please [open an issue](https://github.com/2ez4gcx/game-center-retro-launcher/issues) with `~/GameCenter/Logs/gamecenter.log`.
- The Windows installer is tested automatically on a clean Windows machine: install, uninstall (games and saves are kept), reinstall, and running games with the bundled RetroArch.
- **Arcade games** were tested with the real FinalBurn Neo core but not with real game ROMs. ROM sets made for FinalBurn Neo are recommended.
- **PS2** needs a fairly powerful computer and your own BIOS. Game Center includes no games or BIOS files.
